# 📚 StudySync UI

A responsive StudySync landing page built using **HTML** and **CSS**. This project focuses on creating a clean, modern, and user-friendly interface while improving frontend development skills.

## 🌐 Live Demo

🔗 https://study-sync-six-eosin.vercel.app/



## 🚀 Features

- Responsive Landing Page
- Clean and Modern UI
- Hero Section
- Navigation Bar
- Feature Cards
- Testimonials Section
- Footer
- Mobile Responsive Design
- Pure HTML & CSS (No JavaScript)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Flexbox
- CSS Grid
- Media Queries
